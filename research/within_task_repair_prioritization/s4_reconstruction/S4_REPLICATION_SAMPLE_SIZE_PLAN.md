# S4 replication sample-size plan

**Status:** protocol for a new exploratory-development / independent-replication pair; not a claim about the inaccessible S4-3 execution.

The primary replication unit is one independently generated SCM, with one outcome-blind G0 corruption and its fixed 512-row observational frame. The primary contrast is paired within SCM: `D = Regret(T5_GUIDED_M4, B=1, gamma=0) - Regret(FROZEN_M4, B=1, gamma=0)`. Negative values favor T5. All admitted SCMs remain in the denominator, including no-candidate units where both policies do not edit.

The original-PC S4 pilot was not designed for this contrast. Its `S0−M4,B=2` standard deviations are not substituted for the paired T5−M4 B=1 variance. The maximum confirmatory replication size is fixed at 160 SCMs. The preceding new development phase is capped at 80 SCMs and supplies only a paired-variance / zero-mass precision description. At N=160, the planned interval half-width will be reported as observed; no claim that 160 guarantees 0.010 precision or adequate power is made. No SESOI is declared because there is no defensible operational threshold. There is no outcome-dependent sample-size extension, attrition replacement, or policy reselection.

The target population is the existing proposal builder's accepted, strict-indirect, Q-common-admitted population. A separate structurally enriched cohort is not included in the primary confirmation denominator. The earlier opportunity-rich pilot remains a selected diagnostic sample. A separate matched-corruption estimand is not introduced in this minimum reconstruction.

Analysis uses an SCM-level paired mean and median, better/worse/tie counts at absolute tolerance `1e-12`, and a 10,000-replicate paired SCM percentile bootstrap. The common index matrix is generated once from a locked seed. This is an estimate/precision study under the stated generator, not a broad causal claim about factory populations.
