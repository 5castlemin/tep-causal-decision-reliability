2. Directly apply and evaluate structurally feasible off-task reference corrections on saved S4 units; an omitted M4 edit is never coded as a zero-value edit.
3. Because the other-PC metric-selection Development records are unavailable, use up to 80 newly generated SCMs for a clearly labeled development-only reconstruction. The target is the existing proposal builder's outcome-blind Q-common-admitted strict-indirect population, not an unqualified sample from all Research C proposals. Analyze the six frozen metrics and all 63 subsets; do not use these outcomes to change the previously reported T5 replication candidate.
4. Before any confirmation sample, freeze T5-guided M4 versus Frozen M4 at B=1, gamma=0, paired SCM regret difference `T5 − M4`, with up to 160 new independent SCMs. All units remain in the denominator, regardless of candidate count. This is a new replication, not recovery of the lost S4-3 run. No meaningful-effect threshold is asserted absent an external justification; precision is reported from the paired interval.
