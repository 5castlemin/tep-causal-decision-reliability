# 최종 main 병합 기준

- [ ] Phase 1의 SCM·그래프 universe·지표·분모·미확정 방향·독립 단위·표본/정밀도·비용을 사전 등록하고 승인
- [ ] Phase 2의 15개 조합·baseline·비용·예산 장부·오라클 정보 흐름 검증
- [ ] Phase 3에서 사전 고정 정책의 손실·반례·실패와 구조 단위 불확실성을 완전 보고
- [ ] Phase 4의 실제 발견 표현·가정·실패 및 독립 평가 확인
- [ ] Phase 5 비선형 요인 실험의 실행 또는 명시적 미실행·범위 제한과 별도 승인; 외부환경별 Gate 상태 명시
- [ ] 명령·환경·입력/결과 hash·seed·코드 및 비공개 원본의 적법한 접근 경로를 제3자가 재현
- [ ] 신규 테스트·기존 테스트·CI 및 동결 데이터/그래프/결과 무결성 확인
- [ ] 주장별 분모·독립성·반례·불확실성·원시 근거 대조
- [ ] 연구자 검토 및 사용자 병합 승인. 승인 전 main 병합 금지
