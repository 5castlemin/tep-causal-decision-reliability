# 비용 제약·의사결정 중심 인과그래프 개선

최종 연구 질문: 불완전한 인과그래프에서 제한된 수정 예산이 주어졌을 때 오류 유형과 조작 관련성을 고려한 수정 우선순위가 다운스트림 Decision Regret을 얼마나 줄이며, 그 효과는 비용 구조와 인과환경에 따라 어떻게 달라지는가? 구조 수정 자원의 결정상 가치를 검토한다. 우월성은 가설이다.

FN·FP·REV의 7개 비공집합 각각에 Global과 Task-Focused(T)를 적용해 14개 명목 정책을 구성한다. T는 네 번째 오류 유형이 아니라 위치 우선순위다. 무수정, 무작위 유효 oracle, 기존 Path F1 대표 정책을 추가한다. 실제 정책 구별 가능성과 동일 수정 중복은 Step1~3에서 확인한다. 기존 전체 F1·SHD·경로·조상 지표와 실험은 진단 및 비교 자산으로 보존한다. 이전 15개 지표 조합 설계는 ARCHIVED_METRIC_COMBINATION_DESIGN.md에 보존하며 현재 계약이 아니다.

정확한 계약은 RESEARCH_PROTOCOL.md, 단계는 ROADMAP.md, 상태는 RESEARCH_STATUS.md, 선행연구는 LITERATURE_NOVELTY_MATRIX.md를 따른다. 기존 발견·SCM·추천 코드를 재사용한다. 기존 결과와 신규 계획은 구분한다.
