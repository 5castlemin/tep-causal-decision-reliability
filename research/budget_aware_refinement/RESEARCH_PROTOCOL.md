# Step 0 연구 계약 — 2026-11-10

## 목표와 가설

Cost-Constrained, Decision-Aware Causal Graph Refinement. 동일 예산에서 H1 오류 유형·위치별 후회 개선은 다를 수 있다. H2 Task-Focused 이점은 구역 품질·초기 오류·예산에 의존할 수 있다. H3 상대 성능은 방향 수정 비용과 SCM 구조에 의존할 수 있다. H4 개발 결과가 독립 SCM과 실제 발견 그래프에서 재현되지 않을 수 있다. 모두 확인 전 가설이다.

## 그래프와 수정

주 대상은 고정 관측 V의 완전 방향 DAG, 동일 정답 SCM·DAG, 공통 관측 학습 데이터·추정 방식·후보 조작이다. 정답 인접이 있고 추정에 없으면 FN(추가), 정답 인접이 없고 추정에 있으면 FP(삭제), 같은 쌍의 반대 방향은 REV(원자적 반전 1건)다. REV를 FN+FP로 중복 집계하지 않는다. 쌍당 하나의 오류를 부여하며 모든 중간 결과는 DAG여야 한다. 미확정 방향은 별도 상태이며 주 DAG 코호트에서 자동 방향화하지 않는다. 발견 출력 중 미확정·순환은 별도 적격성/실패로 보존한다.

기존 src/integrated_pilot.py 및 src/diverse_structure_pilot.py는 미확정 간선을 별도 집합으로 유지하고 strict directed F1의 반전 분모에는 FP와 FN이 함께 나타날 수 있다. 이 구조 점수 규약을 수정 비용의 REV 1건과 혼동하지 않는다. 기존 F1·SHD·Ancestor·Path와 과거 결과를 유지한다. 기존 key_path_edge_recall은 거짓 추가 경로를 벌점하지 않으며 새 Path F1과 다르다.

FN/FP/REV의 7개 비공집합 × Global/T = 14개 명목 정책. 후보 수가 같거나 수정이 겹치면 실질적으로 동일할 수 있으므로 Step1~3에서 정책별 후보·수정 순서·Jaccard 중복률·동일 trajectory 비율·예산 소진을 기록한다. 각 정책은 동일한 oracle 후보 풀과 같은 유형 tie 순서 FN→FP→REV 및 노드 사전순을 사용한다. Global은 이 순서, T는 아래 위치 점수 내림차순 후 같은 tie 규칙이다. 수정 시 매번 DAG와 후보 재평가, 각 연산은 한번만 과금한다. 선택 유형 외의 부수적 지표 변화는 모두 기록한다. 참조 방향 정답에 관한 정보를 모델에 전달하지 않는다.

사이클을 만드는 단일 추가/반전은 기각하고 무비용으로 다음 유효 후보를 검사한다. 유효 후보가 없으면 unused budget과 사유를 기록한다. 단일 수정 불가능의 원인을 (1) 실제로 다른 선행 유효 수정 후 가능해지는 순서 의존성, (2) 주 정책의 허용 집합·예산에서 불가능, (3) 구현 오류로 분류한다. Step1에서는 작은 DAG의 전체 유효 수정 순서를 완전 열거해 도달 가능성을 검사하고 원시 후보·거부 로그와 독립 대조한다. 허용 유형 밖 임시 수정이나 사이클 허용은 주 정책에서 금지한다.

No-edit, 무작위 유효 oracle correction(같은 후보/비용, 독립 seed 동결), 기존 Task-Relevant Path F1 개선 대표 oracle 정책을 별도 baseline으로 둔다. Path F1의 후보 universe·미확정·동률 규칙은 Step1에 정의하고 본실험 전 동결한다. 랜덤 기준은 관측 가능한 비oracle 정책이 아니다. 유형 조합별 후보 풀이 비어 있거나 유효 후보 수가 달라 실제 사용 비용이 다를 수 있다.

## Task-Focused 위치 계약

Action X, Target Y와 변수명·공정에서 사전 제공된 인접 후보 정보 H를 결과 전에 고정한다. 초기 추정 DAG G0의 무방향 골격과 H의 합집합에서 거리 d(z,{X,Y})를 계산한다. 쌍 (u,v)의 점수 s=1/(1+d(u,{X,Y}))+1/(1+d(v,{X,Y})); 연결되지 않은 거리의 항은 0이다. 후보 간선이 G0에 없어도 양 끝 노드로 FN의 점수를 계산한다. H가 없다면 빈 집합을 사용한다. 후보 oracle과 접근 가능 예산은 Global과 같으며 점수는 G0와 H만 사용하고 수정 중 갱신하지 않는다. X,Y 자체 외에 숨은 참조 경로·GT 개입 결과는 사용 금지다. H의 출처·시점·접근 범위를 동결하고 해당 정보가 GT에서 유출되면 BLOCKED다. 잘못 지정된 구역의 정답 경로 커버율은 정책 선택 후 진단용으로만 계산하고 낮은 커버 구간·무경로·동률·후회 개선/악화를 보고한다. 진짜 GT 경로 우선 정책은 사용 시 별도 비배포 oracle 진단이다. 구현·구별 가능성은 Step1 검증 전 미확정이다.

## Oracle 정보 경계

정답 DAG는 초기 오류 그래프 생성, 실제 오류 후보·허용 수정 판정, 구조 채점에만 사용한다. 정책에 제공되는 것은 허용된 오류 후보/유형과 G0/H 위치 점수이며 진짜 숨은 경로는 공개하지 않는다. 정답 SCM의 효과·후회로 수정 간선이나 순서를 고르지 않는다. 정책별 동일 학습 관측 데이터로 SCM을 적합해 추천한 후 비공개 GT가 평가한다. 개발 SCM에서 전체 정책 평가·선택 후 정책 정의/순서·하이퍼파라미터·대조군을 동결한다. 독립 SCM에서는 사전 정의된 각 그래프의 SCM 계수만 해당 독립 학습 데이터로 동일 규칙 재적합하며 정책 선택/순서/튜닝은 금지한다. 이는 모델 재적합과 정책 재선택을 구분한다. GT가 들어간 oracle 실험은 현실 배포 가능성의 증거가 아니다.

## 비용·행동·후회

C=n_add+n_del+n_rev, C_gamma=n_add+n_del+gamma*n_rev; gamma=1 주분석, gamma=2,3 비용 강건성. 단위는 구조 수정 자원이며 실제 공정 비용이 아니다. B={0,1,2,4,6}은 파일럿 가능성 확인 후 Step4에서 동결한다. 같은 명목 B에서 실제 사용·잔여 비용을 기록하며 예산 초과 수정은 실행하지 않는다. B-2/B-3/B-4 및 λ 벌점 최적화는 범위 밖이다.

학습 관측 데이터만으로 sample SD(ddof=1)를 계산한다. 공통 행동 A={mean_X+k sd_X:k∈{-1,-0.5,0,0.5,1}}, target_i=mean_Y+delta_i sd_Y, delta∈{-1,+1}은 GT 결과를 보기 전 과제별 균형 지정한다. GT 손실 L_i^GT(a)=((mu_i^GT(a)-target_i)/sd_Y)^2, 모델 추천 a_hat=argmin_a L_hat_i,G(a), Regret_i(G)=L_i^GT(a_hat)-min_a L_i^GT(a). 모델 예측 손실에도 같은 target/sd_Y를 사용한다. 동률은 |k| 작은 순, 다음 k 오름차순이다. sd_X 또는 sd_Y가 0/비유한이거나 필수 입력 비유한이면 실행 전 부적격으로 사유·분모에 남긴다. 적합·추천 실패와 보류는 분리하고 조건부 평균에서 조용히 제거하지 않는다. 실패의 단일 수치 벌점은 Step4 전 미정이며 성공 조건부 결과와 실패율을 함께 보고한다.

GT 평균은 선형이면 정확 계산 우선, Monte Carlo일 경우 호출 정렬을 검증한 공통 난수와 반복 수·오차를 사전 지정한다. 음의 추정 regret은 원시값과 추정 오차를 기록하며 강제 0 처리하지 않는다. 평균반응 제곱손실은 E[(Y-target)^2]가 아니다. 공정 조작비용은 0; 위험·변동성·실제 비용은 범위 밖이다.

## 개발·확인과 통계

기존 개발 SCM과 새 독립 SCM을 분리한다. 생성·오류·과제 수·목표·행동·순서·seed·표본·실패·비용·보조분석을 본실험 전 등록한다. C01~C12와 S1~S8은 새 확인 표본으로 사용하지 않는다. 파일럿 실행시간·SCM 간 변동성·큰 손실 및 동률을 근거로 Step4 전에 독립 SCM 수·최소 의미 차이·정밀도와 자원 한도를 확정한다. 이후 데이터에 따라 임의 변경하지 않는다.

1차 후보는 gamma=1, B=4에서 개발 SCM에서 동결한 최고 정책 대 무작위 oracle, 그리고 동일 정책 대 Path F1 기준선이다. 각 SCM에 중첩된 그래프/과제/데이터 반복을 사전 고정 동일 가중 규칙으로 SCM당 평균한 후, 독립 SCM 간 대응 차이 평균과 SCM 단위 bootstrap 95% 신뢰구간을 보고한다. 두 확인 비교의 양측 p값은 Holm 보정(가족 2개, 유의수준0.05)을 제안하며 Step4에서 고정한다. 우선 정책의 선택과 반복 seed는 독립 SCM 수가 아니다. 표본 수 부족·불안정 구간·실패는 그대로 보고한다.
