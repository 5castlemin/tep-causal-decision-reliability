# CausalMan 인과 계약: 제한 연구 설계 판정

2026-10-29. **CONDITIONAL_REDESIGN.** PR15~25를 일반 병합했으며 이 검토의 기준 main은 `cdb2c7d6dc499937929ca496ca840b07fb500701`이다. 사용자 승인에 따라 이번 11개에 한해 팀원 검토 예외를 적용했다. 별도 팀원 승인 기록은 없다. 기존 연구 A와 TEP 중단, PR25 미수용 증거는 그대로 보존한다.

## 세 연구 접근

| 접근 | 가능한 질문 | 제약 |
|---|---|---|
| A 관측-only 식별 | 식별 가능한 과제에서 구조와 효과·선택 비교 | 기존 Force–품질 ADMG hedge가 타당하면 해당 질의의 일반 비모수 점효과는 관측 분포와 그래프만으로 식별되지 않는다. 참조 자체도 조건부 계층 검증 필요. |
| B 내부 상태 | 추가 상태를 관측하는 합성 생산 SCM에서 구조 오류와 선택 손실 비교 | 어떤 내부 상태를 학습 입력으로 제공하는지 고정한다. 정답 간선·방정식·계수·실제 do 효과를 학습기나 추천기에 제공하는 oracle 진단과 분리한다. 실제 공장 센서 일반화는 별도다. |
| C 관측-only 비식별 | 비식별성과 추정기·정책 실패를 포함한 운영 성능 비교 | 식별 불가능성을 구조 오류의 순수 효과로 부르지 않는다. 공통 정책·보류·실패율과 추가 가정을 사전 고정한다. |

B가 원래 구조–효과–선택 비교에 가장 가까운 **조건부 설계 후보**다. 내부 상태가 추가돼도 조건부 부모 폐쇄와 참조 비간선이 자동으로 검증되는 것은 아니다. C는 관측 조건의 현실적 보조 비교이며 A는 식별 가능한 별도 과제가 확보될 때만 가능하다. 어느 접근도 이번에 공식 채택하지 않는다.

## 참조 구조와 개입

기존 실행에서 101개 경로의 Level 1 활성 모델은 각 157노드·170간선이며 Level 2는 157노드·251간선이다. 81개 차이에는 공급자·부품 종류·경로에 따른 분포 파라미터 관계가 있다. 원본 `sample_batch.py`와 논문은 경로별 조건부 매개변수와 전체 관계의 차이를 설명한다. 그러나 각 간선을 실제 조건부 함수·라우팅 원시 생성 규칙에 일대일로 연결하고 빠진 간선이 참 비간선인지 확인하지 못했다. 따라서 전체 생산라인 모집단의 GT나 관측 MAG/PAG를 채점 가능한 정답으로 확정할 수 없다. Level 1의 81개 삭제나 Level 2의 모든 간선을 활성 식의 직접 부모로 채택하지 않는다.

Level 2의 잠재변수를 주변화한 ADMG/MAG는 방향·양방향 타입을 보존해야 한다. 관측 PAG 동치류의 endpoint와 직접 물리 부모를 혼동하지 않는다. 관측24열과 do observed22열의 차이는 상수 제거 정책이며 baseline 고정 V*가 do full에 포함된다는 사실만으로 GT가 증명되지는 않는다. 내부 상태 경계, 시각과 조건부 경로별 참조 universe, 양성/음성/미확정 쌍 및 발견 출력의 추정 대상이 모두 고정되어야 채점할 수 있다. 새 F1/SHD는 계산하지 않았다.

원본 `fcm.py`에서 `in_edges(node)`는 `(parent,node)` 쌍을 반환한다. 원본은 이 쌍을 다시 `(old,node)`로 감싸 삭제를 놓친다. 최소 **제안**은 `edges_to_remove = [(old, node) for old in old_incoming]`을 `edges_to_remove = list(old_incoming)`으로 바꾸는 한 줄이다. 원본 및 동봉 객체는 수정하지 않았다. 독립 fixture는 목표의 부모만 삭제하고 다른 경로와 원본 graph가 보존됨을 검사한다. 별도의 단순 결정론 fixture에서는 stale 간선과 수정 그래프가 같은 상수 개입 결과를 낸다. 이는 모든 CausalMan 분포의 수치 동등성 증명이 아니다.

실제 upstream `interventional_sample`은 저장된 mutilated graph를 `_sample`에 전달하고, 현재 실행에서는 Force term이 상수로 바뀌어 downstream 계산이 진행됐다. 다만 간선이 남아 Force가 source가 아닌 채 평가되므로 source-node 분기·위상 순서가 바뀔 수 있다. 전반적인 수치 영향은 미확인이다. fixture 통과를 외부 micro acceptance PASS로 승격하지 않았으며 do30000/replay는 실행하지 않았다. 기존 관측14,813·do16000 14,813 내부행, 101/101 부모2개 잔존과 실패 기록은 PR25 원자료에 있다.

## 제한 파일럿의 필요 계약

참조와 발견 출력은 같은 노드·시간·관계 의미를 사용한다. B의 입력 상태 목록과 동결 V*, 학습/검증/최종 평가의 실질 독립 난수·배치 단위를 먼저 고정한다. 원래 생성 그래프는 평가와 통제 오류 생성에만 제공하고 발견·수치 적합·추천에 누출하지 않는다. 같은 데이터·모형 규칙·후보·비용·실패/보류 정책을 사용해 고정 조작 효과 오차와 최종 선택 손실을 따로 평가한다. 수치 개입은 별도 고정된 정확한 버전과 독립 do로 검증해야 한다. 101경로에 effective seed 61개뿐이므로 seed 숫자가 다르다는 사실을 독립성 증명으로 쓰지 않는다. 하나의 topology 반복을 독립 제조공정으로 세지 않는다.

두 핵심 차단은 (1) 81개 조건부 관계와 음성·미확정 간선의 참조 계약, (2) graph 수정의 실제 버전 검증 및 식별 가정·독립 평가 계약이다. micro 한 topology만으로 핵심 경로 지표가 전반적으로 우월하다고 통계적 일반화를 할 수 없다. 이번 결과는 설계 후보이지 실행 승인·GT·연구 가설 검증이 아니다.

## TEP 보존 및 다음 작업

불일치는 단순 계보 부재만이 아니다. 기존 benchmark X7/X8/X9 평균은 약 2800.002/65.004/122.900이고 Python 후보 2시간 평균은 약 2708.451/74.920/120.401이었다. Reactor level 설정은 기존 65%, Python 75%, 온도 설정은 122.9°C 대 120.40°C다. override 정책 차이와 원본 run·median stride/경계·sampling 대응도 남아 있다. 원본과 Python의 정확한 생성 계보는 미확립이며 모든 물리식이 다르다고 증명된 것은 아니다. TEP STOP과 기존 28간선/7개 frozen graph를 변경하지 않는다. 자세한 근거는 `BENCHMARK_COMPATIBILITY_DECISION.md`와 `TRACK_A_RECOVERY_GATE.md`에 있다.

다음 한 작업은 **81개 조건부 참조 간선을 원 생성 파라미터·라우팅 규칙에 연결해 양성·비간선·미확정 범위를 판정**하는 것이다. 증거가 닫히지 않는 간선은 미확정으로 보존하고 GT 채점을 시작하지 않는다. 원본 코드·모델 객체·PR25 trace와 고정 hash가 입력이며, 간선별 출처와 제한이 완료 조건이다. 추가 외부 micro 실행은 하지 않았다.
