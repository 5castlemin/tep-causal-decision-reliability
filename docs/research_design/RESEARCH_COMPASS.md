# 실무용 연구 나침반

**질문:** 불완전한 인과그래프의 어떤 품질 요소와 오류 유형이 실제 개입 추천을 개선하거나 악화시키며, 어느 조건에서 영향이 커지는가?

**목적:** 그래프를 더 정확하게 만드는 것 자체가 아니라, 불완전한 인과관계가 의사결정의 성공과 실패에 영향을 주는 과정을 이해한다. 경로 지표의 우월성을 목표로 하지 않는다. 주변 오류·계수 오류·추천 정책이 더 중요하거나 차이가 없어도 그대로 보고한다.

**연구 흐름:** 관측 자료 → 인과발견 → 불완전한 graph → 구조 평가 → 공통 추천 → 같은 생성환경의 독립 do 평가 → 기준 조작 대비 개선/악화와 실패 원인.

**대상:** 전체 연결·방향 정확도, 조작–목표 경로, 오류의 위치/유형, 효과의 방향·크기 추정, 실제 조작 선택, 추천 가능률. 구조 지표·효과 예측·조작 선택은 서로 다른 단계다.

**결과:** 기준 손실−추천 손실(양수 개선), 추천 손실−후보 최선 손실(추가 손실), 비최적/악화 추천 비율, 큰 손실 사례, 효과 방향·크기 오차, 가용률. 단순 상관은 지표를 바꿀 때의 인과효과가 아니다. 인위적 오류 대조는 실제 발견 graph와 분리한다. 기준 손실≈0이면 손실 비율은 계산하지 않는다.

**현재 범위:** S1~S8/C01~C12는 모두 합성 개발 자료. 시간 지연 없는 선형·모든 변수 관측·독립 잡음 조건이다. TEP 31변수/7개 frozen graph의 구조 채점과 합성 do 결과를 결합하지 않는다. TEP 관측·GT·시뮬레이터의 동일 생성환경은 미확인이고 제조 Recovery/Safety는 미검증이다.

**문서 관계:** `RESEARCH_DESIGN.md`는 원 설계/정의/제조 범위의 기준이며 그대로 보존한다. 이 문서는 새 질문을 대체 승인하는 설계서가 아닌 실무 해석/방향 점검표다. 과거 문서의 미검증 판정은 당시 증거다. 현재 운영 상태는 `docs/research_state.json`, 시간순 이력은 `WORK_LOG.md`, 재개는 `research_runs/decision_reliability_next/CHECKPOINT.md`로 확인한다. 원 설계의 제조 목표와 이번 합성 오류 진단의 범위 차이를 숨기지 않는다.

**방향 이탈 방지:** 작업 전에 “어떤 graph 품질/오류가 실제 개입 추천에 영향을 주는지 이 작업이 어떤 증거를 주는가?”에 답한다. 답이 없으면 우선순위에서 제외한다. MAE 최소화·계산량 확대·특정 지표 지지·시뮬레이터 복원 자체를 최종 목표로 삼지 않는다. 실패/동률/비교 불가도 남긴다. 새 독립 확인은 설계·정밀도·예산 Gate 통과 후에만 실행한다.
