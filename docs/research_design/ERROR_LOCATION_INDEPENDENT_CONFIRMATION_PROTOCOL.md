## 1. 단 하나의 일차 가설과 해석

**H1:** 같은 종류·개수의 오류와 전체 구조 점수를 가진 graph 쌍에서,현재 Action→Target의 핵심 경로 오류가 주변 오류보다 큰 선택 손실을 만드는 경향이 있다.

`ΔL=L(G_key)−L(G_peripheral)`로 정의한다. 양수는 핵심 오류 쪽이 나쁨,음수는 반대다. 동률·반대 증거를 정상적인 결과로 남긴다. graph뿐 아니라 부모집합에 따른 **재적합과 추천까지** 바꾸므로 이 비교는 고정된 전체 분석 파이프라인의 조건부 대비다. 오류 위치의 일반적인 순수 인과효과나 실제 발견 알고리즘 성능을 식별하는 실험이 아니다.

이전 자료는 S8+C12 개발 묶음이다. 당시 C12 확인의 역할과 결과는 보존하지만 신규 확인으로 재분류하지 않는다. PR22에서 확인한162쌍의93악화/4반례/65동률,경로 유지114쌍의48/3/63은 설계 근거이며 새 결과의 예상 성공률이나 검정력으로 사용하지 않는다. 기존0.01 **MAE** 연구와 이번 **선택 손실 차이** 연구는 다른 질문이다.

## 2. 신규 SCM 생성 규칙: 생성은 아직 하지 않음

잠정30개를 두 구조군에15개씩 배정한다. 각 후보의 변수 수는8~10에서 균등 정수 추출한다. 역할은 R,S,P,Q,A,M1,M2,Y와 추가 Z이며,위상 순서는 `R,S,Z들,P,Q,A,M1,M2,Y`다. A와 Y는 계수나 결과를 보기 전에 역할로 정한다. 한 SCM에 과제는 A→Y 하나다.

| 구조군 | 고정 골격 | 목적 |
|---|---|---|
| S:단일 경로 | A→M1→M2→Y | 핵심 간선 오류로 참조 경로가 끊기는 비교 |
| P:병렬·직접/간접 | A→Y,A→M1→Y,A→M2→Y | 일부 경로가 손상돼도 다른 참조 경로가 남는 비교 |

두 군 모두 R→A,R→Y와 S→P→Q→Y를 포함한다. 모든 추가 가능한 순방향 쌍 중 **출발 노드가 R/S/P/Q/Z인 경우에만** 독립 확률0.2로 간선을 더한다. A/M1/M2/Y에서 새로 나가는 간선은 추가하지 않으므로 군별 Action 경로 의미를 유지한다. 전체 간선 수가2n을 넘거나 약하게 연결되지 않은 후보는 자료 생성 전에 기각한다. 간선 수8~20,밀도 분모는 n(n−1)/2다. 노드 수만으로 난이도를 정하지 않고 군·밀도·계수를 기록한다.

각 참조 간선 계수는 독립적인 공정한 부호×Uniform(0.4,1.0),절편0,외생 오차는 서로 독립 Uniform(−1,1)로 정한다. 완전 관측·선형 가산·정적 DAG라는 한계를 유지한다. 총효과의 부호/크기·상쇄·최선 조작·학습 성능을 보고 채택하지 않는다. 거의0인 효과와 기준 조작이 최선인 과제도 남긴다. 숨은 교란·비선형·시간 지연을 추가하지 않는다.

군별 후보 ID1~10000을 사전 순서로 검토해 첫15개 정적 적격 후보를 채택한다. 새로 뽑힌 계수/자료/선택 손실을 보고 후보를 건너뛰지 않는다. 군별 정원을 채우지 못하면 **전체 생성 Gate 실패**로 종료하며,더 큰 후보 pool이나 작은 확인 코호트로 조용히 바꾸지 않는다.

이전20개 및 이미 채택한 새 graph와 라벨을 무시한 유향 동형이면 기각한다. 동일 노드 수에서 간선 한 개 삽입·삭제·반전 이내의 유향 동형도 근접 구조로 기각한다. 계수만 변경하거나 이름만 바꾼 것을 새로운 구조라 부르지 않는다. 이 검사는 실제 생성이 필요한 미래 단계이며 이번에 적격30개 확보를 주장하지 않는다. 후보/기각 사유/비교한 기존 구조 ID를 전부 기록해야 한다.

새 메커니즘·자료 난수는 채택된 고유 topology 목록에 조건부로 독립이다. 군별 정원과 이미 채택한 topology에 대한 중복/근접 기각 때문에 topology 표집 전체를 무제약 iid라고 부르지 않는다. 원시 SCM 단위의 분석과 군 조건부 근사 구간을 쓰며,무제약 graph 모집단에서 구간 포함률이 증명됐다고 주장하지 않는다.

seed는 `ERROR-LOC-v1|20261029|군|후보ID|stream|repeat`의 SHA256 첫4바이트 unsigned 정수로 정한다. topology/coefficients/column_order/train/validation을 분리하고,학습 반복은1~3이다. 먼저 namespace 충돌을 검사하고 충돌 시 `|retry=k`를 붙이는 고정 규칙을 기록한다. 이번에는 hash 규칙만 고정했으며 RNG 호출·구조·계수 추출을 하지 않았다. 무작위 열 순서는 부호화이며 추가 독립 구조가 아니다.

## 3. 대응 오류쌍과 채점 계약

현재 과제의 **모든 참조 A→Y 방향 경로 간선의 합집합**을 K,나머지 참조 간선을 P=E\K로 정의한다. P에는 A/Y의 다른 조상도 포함된다. 주변이라고 해서 목표나 계수 적합에 무관하다는 뜻이 아니다. 주변 간선을 뒤집어 잘못된 새 A→Y 경로가 생기는 경우도 결과로 기록하며 유리하게 배제하지 않는다.

한 종류씩,정확히 한 간선 **누락–누락** 및 **반전–반전**을 비교한다. 각 유형에서 가능한 모든(core edge,peripheral edge) 조합을 열거한다. 같은 참조/자료/과제/정책,오류 종류·개수,Skeleton F1,Strict Directed F1,SHD,간선 수,누락·추가·반전·미확정 수를 일치시킨다. 이 두 오류 종류를 서로 같은 점수로 맞춰 섞지 않는다.

참조 간선 m개에서 누락의 연결/방향F1은 `2(m−1)/(2m−1)`,반전의 연결F1은1·방향F1은`(m−1)/m`이며 둘 다 SHD=1(반전비용1)이다. 이는 **향후 전방향 확정 통제graph의 점수 정의**이며 이번에 새 graph/F1 결과를 산출한 것이 아니다. skeleton은 유한 무방향 노드쌍,direction은 서로 다른 노드의 순서쌍 universe를 고정한다. 참조는 이 합성 생성 DAG이며 공식 제조 GT가 아니다.

반전으로 방향 순환·자기루프·중복 반대 간선이 생기거나 점수/오류 수가 안 맞으면 적합 전에 구조적 부적격으로 기록한다. 정답을 보고 cycle을 끊거나 방향을 고쳐 살리지 않는다. 참조 후보는 최소한 두 오류 유형 모두 한 적격 쌍이 있어야 자료 생성에 들어간다.

두 graph의 정렬된 실제 간선 목록과 source SCM/task/type으로 쌍을 식별하고,동일 graph끼리의 비교 및 동의 명칭 중복을 제거한다. 명목/구조부적격/고유/현재 과제 유효 쌍의 분모를 따로 남긴다. 같은 변형graph가 여러 쌍에 등장하면 한 번만 적합·추천하고 재사용한다. 오류쌍을 독립 SCM으로 세지 않는다.

**일차 분석은 모든 사전 적격 고유 쌍**을 포함한다. 조작이 달라진 쌍만 남기지 않는다. 중요한 보조 분석은 양쪽 graph에 **적어도 한 원래 참조 방향 경로가 그대로 남은 쌍**이다. 잘못 추가된 경로의 도달성만으로 ‘경로 유지’라 부르지 않는다. 원래 경로 유지율,추정 도달성,전체 참조 경로 단절을 별도 기록한다. S군은 이 보조 분석에 해당하지 않고 P군이 주 대상이므로,잠정30개에서 보조 분석의 구조 수는15개다. 부적합 군을0효과로 채우지 않는다.

## 4. 적합·효과 예측·조작 선택

각 SCM에서 독립 학습512행·검증256행을3회 생성하는 계획이다. 쌍 안에서는 정확히 같은 자료를 쓴다. 관측 검증은 MSE 진단만 하며 모형/alpha/과제 선택에 쓰지 않는다. 공통 선형 Ridge와 alpha0.01을 고정하고 train-only 중심화·표준화를 사용한다. 기존 `integrated_pilot.fit_model`의 수치 절차를 재사용할 수 있으나 새 생성·열거·실행 runner가 이미 있다는 뜻은 아니다.

참조graph의 같은 자료 Ridge는 자료당 한 개의 **oracle 진단**으로만 예산에 포함한다. 오류쌍 선정·alpha·추천 튜닝에 쓰지 않고 발견graph 결과로 섞지 않는다. 실제 인과발견 학습은 필요 없으며 계획0회다. 통제graph는 정답 구조를 사용해 의도적으로 만든 변형이다.

| 과제 요소 | 고정 계약 |
|---|---|
| 조작/목표 | A/Y,목표 평균0.6 |
| 후보/기준 | −1,−0.5,0,0.5,1 / 기준0 |
| 비용 | 0.2a² |
| 정책 | 확정 간선 정책 하나. 경로 부재 시 기존 기준0 대체 |
| 동점 | 예상 목적 최소값1e−12 이내 후보를 함께 기록,절댓값 작은 후보 후 작은 signed값 |
| 손실 | `(참조 평균 Y(do(a))−0.6)²+0.2a²` |
| 정규화 | 기존 고정 loss_scale²=1. 기준 손실·개선 가능폭으로 나누지 않음 |

이는 기존 합성 목표/비용에 근거한 고정 computational task이며 제조의 운전/가격 기준이 아니다. 기대 개별 제곱손실과 평균 반응의 제곱손실을 혼용하지 않는다. 목표/비용/후보를 결과 확인 후 변경하지 않는다. 모든graph가 같은 조작을 고르는 경우도 주 결과에 남긴다. 계수 부호·상쇄·경로군에 따른 선택 변동 가능성은 있지만 실제 빈도는 미확인이다.

모든 적합graph에 최적화와 무관한 **do(0.5)−do(0)** 평균 효과를 예측시킨다. 참조 실제 효과·예측 효과의 크기/부호,기준 응답 오프셋을 분리한다. 실제 효과 절댓값≤1e−8은0효과/미세효과로 기록하고 부호 정확도로 억지 채점하지 않는다. 경로 부재의0예측,경로는 있으나 계수가 틀린 예측,모형 실패를 구분한다.

SCM 적합·응답 계산·추천 실패는 원인을 보존하며 graph를 고치지 않는다. **기준0을 실행하는 운영 계약**으로 실패graph의 실제 L(0)을 계산하고 그 쌍을 일차 분석에 남긴다. 결측을0손실이나 큰 벌점으로 대입하는 것이 아니다. 추천 가능률,가용 조건부 손실,전체 운영 손실을 병기한다. 계산된 기준·경로 부재 대체·실패 대체를 구분한다. 모든 비교가 실행불능이면 파이프라인 미평가로 보고하고 귀무가설 지지로 바꾸지 않는다.

기준 대비 개선,후보 최선 대비 regret,잘못된 후보 선택,선택 불일치,손실 동률,효과 오차,큰 악화(`L추천−L기준>1`)와 모든 극단을 보존한다. C07 같은 사례를 삭제·절단하거나 유리한 척도로 줄이지 않는다.

## 5. 평가와 분석 순서

실행을 별도 승인한다면 먼저 generator/분석 코드·버전·PLAN/GATE 해결을 동결하고,정적 적격 구조·계수·과제 hash를 자료 생성 전에 저장한다. 이후 학습·검증→모든 모형/추천 hash 동결→참조 이론 평균 평가→통계 순서다. 모형/추천 입력에는 참조 계수·실제 효과·평가 결과가 들어가지 않는다. GT 사용은 명시적 통제 오류 생성 및 사후 채점/oracle 진단으로 제한한다.

평가는 같은 선형 SCM의 정확한 평균을 사용한다. 조작 방정식을 대체한 위상 순서 계산과 선형계 계산을 독립적으로 대조하도록 계획한다. 둘은 코드 검산이지 두 독립 효과 표본이 아니다. 참조 계산이 비유한/불일치면 전체 cohort를 중단하고 일부 구조를 빼서 통과하지 않는다. **실제 do 표본 생성은 이 계약에서0회**다. 이 선택은 유한 평균 오차를 제거하려는 것으로,새 simulator의 개입 API나 제조 효과를 검증했다는 주장은 할 수 없다.

SCM별 요약 S_s는 (1)쌍별3자료 Δ 평균,(2)유형 안의 모든 적격 고유 쌍 동일가중 평균,(3)누락/반전 유형 동일가중 평균으로 계산한다. 최종치는 SCM 동일가중의 두 군 평균을 다시1/2씩 평균한다. 변형 수가 많은 구조나 군이 더 큰 가중치를 갖지 않는다. 양쪽 경로 유지 보조 분석도 적격 SCM을 단위로 하고 실제 분모를 명시한다.

향후 구간은 군별 SCM 전체를10000회 재표본추출하는 백분위 bootstrap으로 계획한다. 같은 SCM의 자료·graph·쌍은 함께 움직인다. 구조군 고정/중복 기각/선택된 생성 규칙에 조건부인 구간이며 제조 모집단 구간이나 보장된 검정력은 아니다. 관측/do 행을 구조 표본으로 세지 않는다. 이번에 bootstrap·최종 검정은 실행하지 않았다.

일차 지지 규칙은 평균Δ≥0.1이고95%하한>0,반대 증거는 평균≤−0.1이고상한<0이다. 하한까지0.1을 넘는 강한 실질 우세는 별도로 구분한다. 구간 전체가[−0.1,0.1]에 들어오면 작은 차이와 양립한다고 기술하되 공식 동등성 검정이라고 부르지 않는다. 나머지는 불명확으로 남긴다. 평균/쌍/군/유형·유지/단절·실패·동률을 모두 보고하며,하위집단 다중검정을 확인 성공 기준으로 소급하지 않는다.

## 6. 정밀도 Gate: 이전 MAE 예산과 분리

제안하는 실질 차이와 목표95%반폭은 각각 **0.1 선택 손실 단위**다. scale1,기준 목표0.6의 기준 손실0.36에서0.1은 약28%에 해당하는 중간 크기 악화다. 이는 설계 판단값이며 제조 유틸리티나 통계적 정답이 아니다. 옛0.01 MAE 기준을 소급 수정한 것도 아니다. 기존 유리한 평균Δ를 이용해 낙관적 검정력을 만들지 않는다.

기존 중복 제거 쌍을 구조별 평균한 변동과 보수적인 SD2배 시나리오를 사용했다. 기존 동률65/162 및63/114와 극단 C07을 남겼다. 이 자료의 유형/구조 가중이 새 계약과 완전히 같지 않으므로 **분산 대리값을 이용한 민감도**이지 새 generator의 검증된 분산이 아니다.

| 계획용 변동 근거 | 기존 SCM 수 | SD | 제안30에서 분석 SCM 수 | 예상 반폭 | 반폭0.1에 필요한 분석 SCM 수 |
|---|---:|---:|---:|---:|---:|
| 전체 유효 쌍의 구조 평균 | 14 | 1.245862 | 30 | 0.445826 | 597 |
| 그 SD2배 | 14 | 2.491724 | 30 | 0.891652 | 2386 |
| 경로 유지 쌍의 구조 평균 | 10 | 1.465278 | 15 | 0.741533 | 825 |
| 그 SD2배 | 10 | 2.930557 | 15 | 1.483067 | 3300 |

식은 `ceil((1.96×SD/0.1)²)`의 정규 폭 근사다. 새 bootstrap의 실제 폭이나 검정력을 보장하지 않는다. 군 균형을 유지하면 전체 일차는총598개,유지 보조에825개 P군을 확보하려면총1650개가 대응한다. 유지 SD2배는총6600개다. 후속에서 작은 코호트로 줄이거나 동률/실패/큰 손실을 제외해 GO를 만들지 않는다. 30구조가 아주 큰 차이를 관찰할 가능성은 있지만 제안한0.1수준 확인을 보장하지는 못한다.

추가 민감도에서 만약 새 SCM 절반이 모든 비교에서 동률이면 신호가 있는 구조는15개이고,나머지 절반의 조건부 차이0.1도 전체 평균에서는0.05로 희석된다. 동률 SCM을 빼지 않으며 N을 늘린다고 평균이0.1로 복원되는 것은 아니다. 실패 점유율0/5/20/100%의 비용 시나리오도 두되 모두3690개 graph 적합 시도 비용을 계산한다. 한 graph 실패는 여러 쌍에 영향을 주므로 독립 실패로 가정하지 않는다. 한쪽 실패의 기준0 대체는 Δ의 부호를 어느 쪽으로든 바꿀 수 있어,측정하지 않은 손실을 만들어 분산이 줄었다고 계산하지 않는다.

## 7. 계산 예산: 30개는 승인된 실행량이 아님

기존30구조·288학습·90분은 비교 기준일 뿐 자동 적용/충분성 근거가 아니다. 여기서는 인과발견0회이고,288발견 호출과 작은 Ridgegraph 적합 수를 같은 비용으로 세면 안 된다.

| 자원 | 잠정30구조의 상한/계획 |
|---|---:|
| 독립 SCM/자료 묶음 | 30 / 90 |
| 관측 학습+검증 행 | 69,120 |
| 고유 graph SCM 적합(oracle90개 포함) | 3,690 이하 |
| 노드별 Ridge 선형계 풀이 | 36,900 이하 |
| 추천 / 5후보 응답 계산 | 3,690 / 18,450 이하 |
| 대응쌍×자료 셀 | 18,000 이하 |
| 고유 참조 이론평균 / 별도 행렬 검산 | 150 / 30 |
| 실제 do 실행·표본 / 발견 학습 | 0 / 0 |

반복 수를1/3/6으로 바꾸는 비용 민감도는 graph 적합1230/3690/7380회이지만 독립 SCM 수는모두30이다. 반복 수를 줄이면 계산량은 줄어도 구조 간 변동으로 인한 정밀도 문제를 해결했다고 주장할 수 없다. 주 계약은3회로 고정한다.

간선≤20이면 고유 graph는 참조1+누락20+반전20≤41,유형당 core×peripheral≤100이므로 위 상한을 얻는다. 같은graph·후보의 평가를 쌍마다 다시 생성하지 않는다. 정답 평균은 자료 반복에도 공유하고 추천값은 먼저 고정한다.

과거 S8 전체 실행은1001.555초(약16.7분),C12는2433.614초(약40.6분)였다. 여기에는 실제 발견·기타 작업이 섞였다. C12의 시간 기록214개 합2455.141초는216개graph 전체의 순수 Ridge 비용이 아니다. 두 순환graph의 적합 거부와 이벤트 이름을 발견 실행 실패로 혼동하지 않는다. 이 시간으로 새 고유graph 한 개당 비용을 확정할 수 없다.

가정상의 graph 적합+추천 블록0.1/0.5/1초와 고정 overhead1800초를 쓰면30구조는36.15/60.75/91.5분이다. **실측 예측이 아닌 시나리오**다. 모든 관측 배열을 float64로 함께 놓으면약5.53MB,자료 한 묶음은61,440bytes이나 Python/library/graph중복 검사/process peak는 이보다 크다. 1GiB process envelope는 계획상 비교값이지 측정한 최대치가 아니다.

일차 폭 근사의총598SCM은 graph 적합≤73,554회이며,0.1초/블록+overhead 가정도약152.59분이다. 유지 보조까지총1650SCM은≤202,950회·약368.25분이다. 새 장비/병렬성·근접graph 검사 비용을 확인하지 않은 채90분 내 실행 가능이라고 승인하지 않는다. 시간/메모리 상한 중단 시 부분 기록을 보존하고 먼저 끝난 SCM만으로 완료된 독립 확인이라고 보고하지 않는다.

## 8. 최종 판정과 다음 한 가지 결정

**REDESIGN_REQUIRED**이다. 같은 점수의 대응graph 비교와 분석 단위·손실·채택/기각·실패 규칙은 정의할 수 있다. 그러나0.1 정밀도와30개 정도의 자원을 함께 만족한다는 근거,그리고 새 경로의 종단 비용 근거가 없다. 아직 구조30개도 실제 생성하지 않았으므로 확보됐다고 주장하지 않는다.

**GO가 아닌 이유:** 실행 가능한 과학적 대비와 자원·정밀도 준비 완료는 다르다. 기존 양의 평균이나 값싼 산술만으로 그 간극을 덮지 않는다. **STOP을 단정하지 않은 이유:** 더 큰 독립 구조 자원이나 명시적으로 다른 정밀도 목적은 가능하지만 이번에 승인·검증된 것이 아니기 때문이다. 미해결 두 요소를 늘려 문서/기술 시험의 자동 후속 루프로 만들지 않는다.

**다음 한 가지는 자원·범위 결정이다.** 반폭0.1을 유지할 만큼 독립 SCM 자원을 투입할지,그렇지 않다면 독립 오류 확인 확대를 종료하고 PR22의 제한된 Results를 활용할지 결정해야 한다. 기준을 낮춰30개 실행을 GO로 포장하지 않는다. 이 결정 전에는 새로운 실행 명령을 제공하지 않으며,기존 `run_diverse_structure_pilot.py`가 새 계약을 구현했다고 주장하지 않는다. 신규 runner도 이번 범위 밖이다. 실행이 승인될 경우에는 이 PLAN/BUDGET/GATE의 해소 기록과 구현 hash를 먼저 고정해야 한다.

PR22에서 분기한 미병합 후속 작업이며 원설계·기존 TEP/합성/동결 자료는 보존한다. Python TEP 공식 채택/재개,기존 가설 변경,PR 자동 병합은 없다. 실제 정적 검사와 예산 산술·기존 보존 검사는 같은 폴더 `validation/`에 기록한다.

실제 로컬 검사: JSON/예산 산술/불변 입력16개 hash/보존 검사 PASS. 기존 전체96단위검사 PASS(신규0),상태 JSON-MD·동결39SHA/변수·환경계약·asset 검사 PASS. 기존 보호파일5159개 불변. 기존suite의 과거 적합/CV 재검산은 새 실험용 모형 적합이 아니며,새 SCM·자료·실험적합·do·최종 검정은0이다. 원시 출력을 덮어쓰는 `verify_recovery.py` main은 실행하지 않았다.
