# 공식 TEP 실행 및 동일환경 판정

2026-10-30. **OFFICIAL_SIMULATOR_RUN_VERIFIED_ENVIRONMENT_UNVERIFIED**. MATLAB R2026b Update 1와 MinGW 14.2에서 공식 모델을 별도 감시 사본으로 실제 실행했다. Phase A는 CLOSE_CANDIDATE_BUT_UNVERIFIED이며 Phase B는 실행하지 않았다.

## 실행 근거

PR #31 HEAD c01e2c3 기반이며 원본 ZIP·동결 그래프는 보존했다. 기존 MATLAB 환경·MEX·모델 로드 로그를 확인했고 공식 C 사본에 기록 및 중단 검사만 추가했다. 물리 함수와 제어기 식은 변경하지 않았다. 차이는 Git 제외 실행 폴더의 monitor.diff 및 EXECUTION_MANIFEST.json의 해시로 식별한다. 모델의 TEplot 종료 콜백은 런타임에서 비활성화해 그래프 표시 실패가 원시 자료를 방해하지 않게 했다. ode45와 공식 초기화 및 기본 저장 설정은 유지했다.

실제 입력·센서·상태는 C S-function의 mdlOutputs에서 tefunc 평가 후 읽었다. 41개 센서·12개 적용 cache 명령·50개 상태·시간·중단 코드를 매 major output에서 즉시 파일에 기록하고 닫는다. 센서 압력3000kPa, 온도175°C, 원자로/분리기/스트리퍼 액위0~100%, 명령0~100%, 상태·센서·명령 비유한값과 native shutdown을 감시했다. 물리 상태는 유한성만 확인했고 상태별 안전 범위는 미검증이다. 모든 minor derivative 평가를 감시하는 것은 아니다.

검증용 중단 플래그를 주입한 A0 시험은 요청0.001h 중 0.0005h에서 reason99로 중단됐다. 이는 실제 계산 중 중단과 즉시 로그 보존을 검증했으나 각 수치 분기별 주입을 모두 검증한 것은 아니다. 이후 정상 짧은 A0, 10분 A1, 2시간 A2, 6시간 A3는 모두 reason0으로 완료됐다. TElib의 Simulink5 계열 및 Classic initialization 구형 경고는 남았지만 실행 오류는 없었다. 지원되지 않는 자동 모델 변환은 하지 않았다.

**핵심 진전:** 공식 기본 실행의 XMV5/9/12는 0/0/100이다. 초기화 스크립트의 literal 명목값이 아니라 Mode1xInitial을 불러온 전체 Simulink 초기 상태와 제어 연결이 적용된다. 이전 Python/Studio의 22.21/47.446/50과 실제로 다른 설정이다. 이 증거는 이전 명목값만 복사하는 접근의 한계를 보여주지만, 현재 CSV의 정확한 raw run 계보까지 입증하지 않는다.

## 동일환경 판정과 연구 차단

31변수 평균·표준편차·분위수·자기상관 및 상관행렬을 저장했다. 가장 큰 표준화 평균 차이는 X20 약 -5.81, X21 약 +3.12였으나 원시6시간과 가공75시간을 동등성 검정으로 비교할 수 없다. X27/X31의 실제 제거 코드, 1499/1500행 차이, 원본 noise와 시계·창·경계 처리, 변수 매핑의 원본 export 근거가 없다. 수치 동등성 허용오차를 사전에 정량 지정하지 못했으므로 통계적 동등성 검정은 미실행이며 결과에 맞춰 임계값을 만들지 않았다.

공정 실행과 보고된 운전점은 강하게 지지되지만 A~E 조건 전체는 미완료다. 따라서 MATCHED와 연구 재개를 선언하지 않고 기존 그래프/SCM과 새 개입 결과를 결합하지 않았다. 실제 개입·고장·추천·구조 지표 비교는 NOT_RUN이다. 원본 28간선의 완전성도 별도 문제다.
