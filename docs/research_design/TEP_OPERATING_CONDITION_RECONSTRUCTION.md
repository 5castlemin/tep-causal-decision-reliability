# TEP 원본 운전 조건 복원 및 불일치 검증

2026-10-29. 판정 **ORIGINAL_OPERATING_CONTRACT_NOT_ESTABLISHED**. 사전 고정한 안전 중단 기준에 따라 B 조건이 약 1.519시간에 중단되어 6시간·24시간 운전은 실시하지 않았다. 이는 Studio 측정 제약 위반의 실제 증거와 원본 실행 계보 부재에 관한 판정이지, 원본 공정 방정식이 전부 다르다는 증명이 아니다.

## 원본 문헌과 운전 조건

[Manca 기술보고서 §1.2–1.3, 2.1–2.3](https://www.researchgate.net/publication/355917633_Tennessee-Eastman-Process_Alarm_Management_Dataset_-_Technical_Report)은 2015 수정 모델과 Ricker 분산 제어, 정상 운전에서 순환 압축기 재순환 밸브 XMV5 및 스트리퍼 증기 밸브 XMV9 폐쇄, 교반기 XMV12 100%, 0.1 Hz 기록을 보고한다. 같은 보고서의 세 정상 자료는 각각 75시간이다. [CIPCaD 논문](https://arxiv.org/html/2208.01529)은 Manca 자료 및 3분 이동 중앙값 처리를 설명한다. 이 문헌 연결은 유력한 근거이나, 현재 1499행이 어느 원시 실행·seed에서 추출됐고 그 명령이 어떤 포트에 적용됐는지와 3분 창 경계/첫 행 처리까지 직접 확인한 것은 아니다. 원본 33열이 없어 X27·X31이 분산 0으로 제거됐다는 인과적 연결도 추정이다.

Studio 소스의 0부터 시작하는 배열 위치는 각각 4, 8, 11이며 기본 명령은 22.21%, 47.446%, 50%다. 앞의 두 값은 밸브 명령이고 물리 상태는 내부 동역학으로 움직인다. 교반기 값은 속도 명령이며 일반 밸브와 구분한다. 공식 `.mdl`에서 유사 이름이 제어기 외부 setpoint 블록에 쓰이기도 하므로 블록 이름만으로 입력 번호를 판정하지 않는다. 원본 CSV와의 정확한 명령 적용 계보가 확인되지 않아 사전 계획에 따라 C/D 조작 고정 시험을 수행하지 않았다.

## 제어기 및 시간 계약

공식 `.mdl`에서 실제 추출한 17개 PI 블록의 비례 계수, 적분 시간, 주기 및 표기된 상·하한이 Studio registry와 일치한다. 루프별 입력·출력과 수치는 `CONTROL_DIFFERENCES.csv`에 기록했다. 이는 코드상의 정적 수치 대조로, 공식 Simulink의 초기 적분 기억·workspace와 PI 실행, 신호 연결 및 호출 순서까지 일치한다는 증명은 아니다. 압력은 `Kc=-1e-4`, 적분 시간 20/60시간인 제어기에서 purge 유량비를 거쳐 XMV6을 조절한다. 레벨은 separator 냉각 제어의 목표로 전달된다. Studio는 초기 측정으로 목표 및 PI 기억을 설정하고, 생산·조성 목표에 ramp를 사용한다. Studio의 %G feedback 및 override 기본 비활성과 원본 실제 설정의 관계는 미확정이다.

두 구현은 같은 공정 코드 세 파일이지만 공식 `ode45`와 Studio `RK4`를 사용한다. 양쪽의 수치 계산 간격 및 잡음 호출 순서가 다르다. 이번 중단 기준 때문에 별도 내부 적분 간격 수렴 검사는 **미실행**이며, 적분 방식의 정량적 영향을 알 수 없다. Studio의 공정 계산·제어 주기는 0.0005시간, 기록은 6단계마다 약 10.8초다. 원본 0.1Hz 및 3분 중앙값과 동일한 시계가 아니며 분석기 지연도 고려해야 한다. 시간별 공식 trace는 없어 정적 비교만 수행했다.

## 실제 순차 시험

실험 전에 `EXPERIMENT_PLAN.json`과 실행 코드를 커밋했다. 고정 Studio commit `852f0c69ab974540750d61bd1dbfafd56bfd80bb`, seed 465120799, no-fault, 새로운 공정 객체, 1.8초 제어 및 RK4 간격이다. 각 단계에서 상태·출력·명령의 유한성과 명령 범위를 검사하고 schema의 제약 여유가 0 이하이거나 종료·오류가 발생하면 모든 후속 시험을 중단한다. 한 seed의 동일 재현은 독립 반복이 아니다.

**선행 기록에 대한 중요한 보완:** PR #28의 B 원시 시계열에서도 1.519시간에 같은 XMEAS15=100.623554%를 확인했다. 당시 2시간 성공은 native shutdown과 비유한값이 없다는 사실이었다. 측정 제약을 매 단계 검사하지 않았으므로 제약 준수 또는 안정된 정상 운전을 뜻하지 않는다. 과거 파일은 수정하지 않는다.

6시간·24시간 수치, 2800 kPa/65%의 장기 수렴 여부는 미실행으로 답할 수 없다. A도 사전 정의한 후반 추세 진단에서 압력의 2시간 선형 변화가 약 1.47 kPa/h로 원본 표준편차 기반 기준을 넘어 장기 안정으로 선언하지 않는다. B는 2시간에 못 미쳐 해당 진단 자체가 불가능하다. 별도 적분기 시험, C/D 고정 조작, 개입, 고장복구 및 신규 그래프 학습은 수행하지 않았다.

## 31변수와 남은 제약

`VARIABLE_MAPPING.csv`는 기존 잠정 대응표이며 원본 파일명·단위·측정 시계의 직접 매핑을 아직 보증하지 않는다. `COMPARISON_31.csv`는 원본과 A의 2시간, B의 중단 전 약 1.519시간에 대해 평균·표준편차·분위수·상대 및 표준화 차이·자기상관·후반 평균과 추세를 기록한다. `RUN_RESULTS.json`에 원본과 두 실행의 상관행렬을 보존한다. 기간과 전처리가 달라 숫자는 탐색적 기술 비교다.

잠정 X16은 Studio stripper pressure, X19는 stripper steam flow다. X19의 원본 평균은 약 -0.012이고 A는 약 227.74이지만 단위와 매핑·원본 정책이 확인되지 않아 원인을 확정할 수 없다. 원본 X19의 작은 표준편차로 표준화 차이도 매우 크지만, 이는 원시 2시간 대 가공 75시간의 동등성 검정이 아니다.

원본 생성 계보, 공식 제어 실행 trace, 시간·잡음·전처리, 28개 참조 간선의 양성·비간선 의미가 확정되지 않았다. 7개 기존 그래프를 보존할 수 있으나 Studio 개입 결과와 기존 구조 점수를 연결할 수는 없다. 원본 제조 연구의 유력한 경로로서 복원 가능성은 남지만, 현 상태에서 제약 위반을 무시하고 장기 시험을 연장하지 않는다.
