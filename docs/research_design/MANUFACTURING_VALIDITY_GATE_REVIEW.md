## 6. 낮은 인과발견 성능과 설정 선택

이번7개 지표 재계산은 동일31변수 순서·같은 GT·같은 엄격 규칙과 일치했다. 시차 graph는 원래 lag tensor를 보존하면서 전역 표에서는 엄격 static projection을 채점한다. 이 표가 lag별 식별 정확도를 측정하는 것은 아니다. cycle의 존재를 SHD가 별도 처벌하거나 식별 문제를 해결하는 것도 아니다.

경로부재 비율은 **구조가 해당 confirmed-only 정책에 들어갈 수 있다고 가정한 조건부 규칙 진단**이다. 12과제×7graph를 실제 fitting/추천한 비율이 아니다. PCMCI+ cycle 및 temporal 표현/정적 투영 때문에 직접 추천에 넣을 수 없는 경우를 숨기지 않는다.

198조작–목표쌍에서 기존 GT상 도달65/비도달133이 재확인됐다. VarLiNGAM은 GT도달 중48개를 연결하지만 GT비도달133중89개에도 확정 도달이 있다. DYNOTEARS는42/58,PC는1/0이다. 밀도가 높아 경로 recall이 높아지는 것을 실제 좋은 효과 예측으로 해석할 수 없다. 이 불일치는 **참조 graph 기준**이며 물리적 효과 부재/존재 검증이 아니다.

기존 config와 보고된 선택 규칙은 PC의 인접alpha Jaccard 안정성/비순환·희소 tie-break, BOSS의 n_eff 기반 penalty(8.4951),Direct/DAGMA B-tune-v2의 BIC_eff·threshold/gamma 기록,VarLiNGAM/DYNOTEARS의 BIC_eff 및 희소 tie-break,PCMCI+의 고정 TrackA 설정 재실행이다. 정확한 생성 bytes가 모두 회수된 것은 아니므로 **설정 선택에 GT가 없었다는 보고와 실제 코드로 검증한 누출 부재는 다르다.** config/GT-guard hash·보고서를 근거로 삼되 누출을 완전히 배제하지 않는다. 최종 개입 평가를 보고 retune했다는 증거는 없고,당시 독립 제조 효과 평가 자체가 없었다. 사후 F1 튜닝은 수행하지 않았다.

### 무작위 기준선 검산

원본 평가 ZIP SHA `28824bc2a98acb77ce8fc5f56439ea4910f7dc9f22ed45b7d1391f7f703f6b22`,원본 random_baseline.py SHA `d20a117cb5a3c9140851e6ab2ed949b2b332ee3224103eb93aad6334121ef43f`는 FREEZE와 일치했다. 동일 쌍 수·미확정 수를 유지해465쌍에서 균등 추출,나머지 방향을 동전 던지기로 정한 기존10,000회 자료를 재집계했다. 새 무작위 graph를 생성하지 않았다. 방향 F1 단측 p는 PC .027797/BOSS .025297/Direct .009499/PCMCI+ .008099, DAGMA .165883/Var .359964/DYNO .473453이었다. 모든 알고리즘이 방향 기준선을 개선한 것은 아니다. 여러 비교/설정 선택/한 GT에 조건부이므로 보편적 유의성·우월성을 주장하지 않는다. 무작위 baseline은 DAG/controller/lag의 제약도 보존하지 않는다.

평가기 버전은 구분해야 한다. 회수 ZIP의 evaluator SHA는 `5d120b84…`, Final FREEZE가 기록한 evaluator SHA는 `c8af472a…`로 다르다. 회수 버전으로 엄격 지표가 일치하는 것을 확인했지만 Final 생성 코드 전체/보조 U규칙까지 byte-identical 재현했다고 주장할 수 없다. random_baseline.py의 SHA 일치와 평가기 버전 차이는 별개다.

저장 draw CSV는 소수 반올림으로 F1 동률이 어긋날 수 있었다. BOSS 방향/Direct 연결/DYNO 방향의 naive CSV p가 원래 표와 달랐다. 고정 분모의 `F1=2TP/(m+28)`에서 TP를 복원했다. 최대 반올림 오차는 .001 TP 미만으로,정수 간격 .5보다 훨씬 작아 유일하게 복원 가능하다. 이 동률 보존 통계로21개 baseline 평균/p가 원래 표와 일치했다. 원표를 바꾸지 않았고 실패한 reader/정밀도 가정도 보존했다. 유리한 p를 만들려고 허용오차를 튜닝한 것이 아니라 원래 이산 통계를 복원한 것이다.

원본 CSV의 lag1 상관은 최소−.0984/중앙.5712/최대.9816이었다. 자기상관으로1499행을 독립1499표본으로 취급하기 어렵고,freeze의 Bartlett n_eff≈114와 별개로 AR1 주변 heuristic도 기록했다. 유효표본수의 정확한 추정/비선형·숨은 변수의 검정은 이번에 하지 않았다. 물리식의 비선형성·제어 피드백·관측하지 못한 상태·분포/비정규성·시간 축약은 가정 충돌 가능성이며 단일 원인으로 확정하지 않는다.

**Q1:** 낮은 F1 자체는 불완전성을 연구하는 목적을 막지 않는다. 다만 비교 가능한 환경/유효 참조가 없고 추천이 대부분대체라면 제조 가설을 검증할 수 없다. 참조가 불완전하면 낮은 F1을 순수 알고리즘 오류라고 단정할 수도 없다.

**Q2:** 수치적 변동은 있으나 독립7표본은 아니다. 하나의 관측자료/GT,알고리즘·밀도·방향 표현·시차 투영이 함께 달라지고 실제 효과 label도 없어 유효한 제조 추천 성능 비교의 정보는 부족하다.

**Q3:** 먼저 노드·시간·간선·개입의 평가 정의를 맞춰야 한다. 그 다음 자기상관/제어·잠재상태/비선형 가정과 생성 계보를 검토한다. 재생성·다른 알고리즘·새 평가 규약 중 어느 하나가 해결책이라는 근거는 없다. 기존 동결 채점은 보존하고 새 규약은 별도 버전/승인이 필요하다.

## 7. 지표와 수치 인과모형 감사

| 지표 | 정의·이점 | 빠지는 것·중복/위험 |
|---|---|---|
| 연결 F1 | 쌍 TP에 대한2TP/(예측쌍+GT쌍),추가/누락 모두 반영 | 방향/오류 위치·계수/총효과 무관;희소/밀도·크기 영향 |
| 엄격 방향 F1 | 정방향 확정 TP,분모는 미확정 포함 전체쌍+GT쌍 | 미확정도 TP0으로 방향 오류와 식별 불가능 혼재;확정 방향 precision 별도 필요 |
| SHD | 누락+추가+역방향+GT미확정 | 같은1오류라도 손실 다름;노드/간선수가 다른 경우 raw값 직접 비교 제한 |
| 경로 간선 복원율 | 나열한 GT경로의 간선 **합집합** 중 확정 복원 | 추가된 잘못된 경로를 감점하지 않음;분모·경로선정·정책 경로확인과 기계적 연결 |
| 완전 경로 비율 | GT 나열 경로 중 모든 간선 복원된 경로 비율 | 중첩 경로 의존·경로 개수 편향·추가경로 무감점;도달성과 다름 |
| 확정 도달성 | 추정 확정 graph의 Action→Target 경로 존재 | 어떤 경로든 true로 밀도에 유리;GT상 비도달쌍 불일치를 함께 봐야 함 |
| 직접X→Y 정확도 | 정확한 방향의 직접 관계 상태,미확정은 null | 간접 총효과와 다름. 간선 없는 다수쌍에서 단순 정확도는 높을 수 있음 |

핵심은 연결/엄격 방향 F1과 과제 경로/도달을 함께 보되,오류 분해·밀도·직접XY는 진단으로 사용한다. 새 복합 지표나유리한 순위를 만들지 않았다. 합성 개발 자료에서 방향과 경로 상관≈.908·방향과정규화SHD≈−.977은 중복 위험을 보여주지만 TEP에서도 같은 수치라고 가정하지 않는다. 지표 추가 정보는 실제 별도 효과 평가가 있어야 판단할 수 있다.

관측 Ridge MSE가 낮아도 식별은 보장되지 않는다. 잘못된 부모의 계수는 생략변수/제어 내생성을 흡수할 수 있다. 기존 정답구조 oracle 적합과 인위적 동일오류 대조,고정조작 효과 예측,경로 유지 대조,세정책 비교는 **부분 분리** 근거이며 구조/계수의 일반적 인과 기여 완전 분해가 아니다. C07의 기울기/절편 완벽정보 대조도 deployable 보정법이 아니다. 추정graph에 확정경로가 없으면 기준 조작으로 가는 규칙은 경로점수에 유리한 관계를 만들 수 있다. 전체결과/고정조작/경로존재 subset/경로유지오류쌍을 분리해야 한다.

실제로 수행한 비선형 SCM fitting/독립효과 비교 산출물은 이번 관련 저장소 근거에서 확인되지 않았다. 비용·후보 간격·잡음 분포 민감도는 비선형 모형 검증이 아니다. 선형 합성 결과만으로 비선형·피드백 제조 결론을 주장할 수 없다.

## 8. 다음 실험: 조건부4셀 설계(아직 실행 안 함)

동일하고 유효한 참조/관측/독립do 환경을 확보한 뒤 **정답구조×선형/비선형,불완전구조×같은 선형/비선형** 네셀을 비교한다. 정답구조는 oracle 진단으로 분리한다. 새로운 전체 GT를 구성하지 않는다.

입력은 환경source/설정/hash,노드·단위·시간·개입계약,학습/선택/최종평가 분리,고정graph 및 진단용참조다. TEP 기술 후보는 XMV10 명령/실제밸브를 구분하고 XMEAS9를 관찰한다. 물리 허용범위,정상목표,비용의 물리적정당화,평가horizon,Fault/Recovery/Safety 기준은 **미확정**이며 가상값을채우지 않는다. 기술smoke의±.1pp/60step을 안전한연구과제범위로 승격하지 않는다.

선형은 공통 Ridge/기존 train-only 선택을 유지한다. 비선형은 예를 들어 사전고정 HistGradientBoosting(max_depth3,max_iter100,learning_rate.05) 한family만 제안하며 이는 **미실행 설계값**이다. 같은 부모/전처리/관측자료/후보/비용/seed·horizon과 동일한 tuning예산을 적용하고 GT/F1/최종효과로 튜닝하지 않는다. 부모없는식은상수/잡음,cycle/방향미확정/latent 식별 제약은모형family와별도로 처리한다.

비선형에서는 평균상태에함수를넣는 것과함수평균이달라 잔차0 대입만으로do평균을구하지않는다. train-only잔차/잡음 적분과 전개를 별도 검산해야하며 잘못된graph의잔차독립성을인과적사실로가정하지않는다. 추천/하이퍼파라미터를고정한뒤 미사용시뮬레이터do를평가하고 관측MSE·고정조작효과방향/크기오차·최종손실/가용률을분리한다. 같은seed가잡음행대응을보장한다고가정하지않는다.

성공은 높은F1이나복구점수가아니라 계약일치·실제명령반영·동일조건반복·원시로그·동일참조/효과평가·실패포함이다. 효과/추천의실질적성공 수치와물리문턱은출처/과제확정전미정이다. 환경·참조식별·독립평가가미충족이면4셀은실행하지않는다.
