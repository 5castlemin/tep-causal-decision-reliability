# 핵심 경로 지표의 추가 예측력: 통합·운영 평가·정밀도 Gate

기준일: 2026-10-25. 원래 연구 질문은 **불완전한 인과그래프의 어떤 품질 지표가 실제 개입 추천 성능을 설명하는가**이다. 이번 결과는 인공 선형 가산 환경에 한정한다. 제조공정의 복구·안전 성능을 검증한 결과가 아니다.

**현재 판단은 5번, 정밀도·실험 제약으로 새로운 독립 확인 결론을 내릴 수 없음이다.** 개발 자료에서 경로 지표의 추가 정보는 유망하지만, 안정적인 우월성이 확인되지는 않았다. 실제 통합, 재분석, 이론 평가 구현, 새 do 표본 검산은 수행했다. 새 독립 구조 및 새 인과발견 학습은 정밀도 Gate 때문에 실행하지 않았다.

## 2. 평가 표본 오차와 이론 평가의 분리

이전 S1~S8 및 C01~C12는 **모두 개발 자료**다. 두 묶음의 360개 기존 학습 graph를 다시 학습하지 않고, 기본 direct/path 40개 과제와 세 추천 정책의 2,160개 시도를 평가했다. 같은 graph·데이터·정책 행은 독립 구조가 아니다.

생성 방정식의 계수행렬 B에서 조작변수의 방정식 행과 잡음 분산을 제거하고 `(I-B)^-1`로 평균·분산을 독립 계산했다. 기존 위상순서 계산과도 대조했다. 이론값은 **평가 단계에만** 사용한다. 기존 추천 조작은 변경하지 않는다.

손실은 `(개입 평균-목표)^2 + 비용`이고 추가 손실은 원래 `loss_scale²`로 나눈 최선 후보 대비 손실이다. 개별 표본 제곱오차 평균과 다르다. 기준 조작이 최선이면 추가 손실은 0일 수 있지만, 기준 조작 자체의 손실을 0으로 대입하지 않는다. 기준 정책 개선폭으로 나누지 않으므로 C07처럼 개선폭 0인 경우에도 분모 폭발이 없다. 대신 기존 척도가 어려운 과제를 충분히 정규화하지 못하는 한계는 남는다.

기존 do 자료의 296개 변수·조작 조건에서 표본 평균 오차 RMSE는 N=128/256/512/768에서 각각 0.264960/0.183708/0.132550/0.118890이었다. 상관된 prefix에 대한 진단이며 독립 반복 수가 아니다. 원래 5개 조작 후보의 최선 조작이 이론값과 달랐던 과제 수는 각 N에서 7/40, 5/40, 4/40, 2/40이었다. 이는 기존 #14의 다른 설정을 포함한 15/96 집계와 분모가 다르다.

동일한 과제 특징·운영 행·구조 단위 검증에서 표본 기반 결과를 사용할 때 연결 F1 이후 경로 추가의 개선은 0.008338, 이론 결과에서는 0.005200이다. 따라서 유한 표본 오차가 차이에 영향을 준다. 과거 #14의 MAE와 이번 값을 직접 전후 개선으로 해석하면 안 된다. 평가 대상, 운영 실패 정책, 사용한 구조와 과제 특징이 달라졌다.

## 3. 추천 불가능 사례의 운영 계약

실패는 순환 graph, 적합/학습 실패, 비순환 완성/보조정책 실패로 구분한다. graph를 정답으로 고치지 않았다. 시도 2,160개 중 2,136개(98.89%)가 기존 정책 결과를 반환했고, 24개는 실패 후 기준 조작 0을 실행하는 운영 계약으로 평가했다. 2개 PC 순환 graph와 3개 보조 정책 완성 실패 graph가 여러 과제·정책 행으로 반복되는 것이지 24개의 독립 학습 실패가 아니다.

| 결과 구분 | 행 수 |
|---|---:|
| 실제 계산으로 비기준 조작 선택 | 986 |
| 실제 계산으로 기준 조작 선택 | 340 |
| 확정 경로 부재로 기준 조작 | 553 |

추천 가능률, 가능한 경우의 조건부 손실, 실패까지 포함한 운영 손실은 별도 저장한다. 실패 후 기준 조작 평가는 명시한 정책의 실제 이론 손실이며 결측을 임의 큰 값이나 0으로 채운 것이 아니다. 반환된 결과와 최적화를 수행한 1,326행도 구분한다. 발견 학습이 아예 실패해 graph가 없는 향후 사례는 F1을 부여하지 않고, 운영 성능/가용률을 별도 보고해야 한다.

## 4. 과제 정보·추가 예측력 비교

평균절대오차(MAE)는 구조를 통째로 제외하는 검증(LOSO)으로 계산한다. 표준화·결측 특징 대체·회귀 적합은 나머지 19개 구조만 이용한다. 구조별 MAE에 동일 가중치를 준다. Ridge 강도 0.01, 음의 손실 예측은 0으로 제한한다. 저장 artifact의 `nonnegative_forecast_constraint`는 이 wrapper 제한을 나타내며, 재사용한 기본 추정기의 원시 예측 여부와 구분한다.

M0에는 알고리즘, 표본 수, 변수 수, 학습 graph 밀도/방향 미확정 비율, 정책, 관측 자료의 목표·조작 규모, 목표와 관측 평균 차이, 범위·후보 간격·비용, 학습 graph의 노드 역할·추정 경로·SCM 고정 조작 효과를 포함한다. 변수명 자체는 사용하지 않으며 이름 치환 불변성을 테스트했다. 정답 효과·최선 조작·추천값·실제 결과는 특징 입력에서 금지한다. 경로 F1 등 품질 지표 자체는 **정답을 아는 인공 벤치마크의 평가용 정보**이며 현장에서 항상 알 수 있는 값이 아니다.

## 5. 알고리즘·방향·추천 규칙 영향

방향 F1과 경로 복원율의 기술적 Spearman 상관은 0.9084, 방향 F1과 정규화 구조 오류는 −0.9771이었다. 중복이 크므로 Ridge 계수를 개별 인과 기여로 해석하지 않는다. 알고리즘 내부 재적합 예측, 동일 학습 자료의 알고리즘 쌍, 정책별 예측과 추천 결과를 분리 저장했다.

확정 정책에서 경로 복원율과 추천 손실의 기술적 상관은 전체 −0.7425, 확정 경로가 남은 349행에서 −0.4854였다. 최적화 없이 모든 적합 graph에 do(0.5)−do(0)을 예측시킨 오차와의 관계도 각각 −0.7472/−0.5474였다. 따라서 경로 부재 대체 규칙만으로 전부 설명되는 것은 아니지만, 경로 존재로 선택한 집단의 편향과 다른 지표·알고리즘 차이는 남는다.

PC 내부의 고정 조작 효과 오차 관계는 0.0209로, 전체 합친 관계와 다르다. DirectLiNGAM의 경로 점수는 두 값뿐이어서 내부 관계 비교 불가로 기록했다. 비정규 선형 오차라는 유리한 가정 및 BOSS 점수의 분포 가정 차이를 유지한다. 한 알고리즘에서 변동성이 부족하다고 효과가 없다고 결론 내리지 않는다.

같은 720개 graph·과제 셀에서 확정 정책 대비 최악 손실 최소화 정책은 98개 개선/4개 악화, 불일치 보류 정책은 25개 개선/7개 악화였다. 정책 변화가 성능에 영향을 주므로 지표의 인과효과라고 해석하지 않는다. 기존 #14의 경로 유지 통제 오류 실험은 보존·검사했지만 이번에 새 구조에서 재실행하지 않았다. 인위적 오류와 실제 발견 graph도 합치지 않았다.

## 6. C07의 큰 오차

C07을 제외하지 않았다. 경로 과제의 이론 총효과는 8.813814, 목표는 0.6, 5개 후보의 실제 최선은 0이었다. 큰 총효과 때문에 가장 작은 양의 후보 0.5조차 지나치게 크다. 관측 목표 SD는 약 13.62이며 원래 손실 척도는 1이다.

BOSS 6회 중 1회가 조작 1을 선택했다. 그 조작의 이론 손실은 67.666749이고 기준 조작의 손실은 0.36이다. 낮게 추정한 평균 효과가 과도한 조작으로 연결됐다. 반면 PC는 모두 경로 부재로 기준 조작을, DirectLiNGAM은 계산을 통해 기준 조작을 선택했다. 동일 조작이라도 의미가 다르다. 직접 과제의 총효과는 1.1055이며 최선 조작은 0.5로, 두 과제의 난이도도 다르다.

C07 제외 재적합 민감도에서 M0/M1/M4/M5/M6 MAE는 0.113540/0.114175/0.112120/0.111854/0.111355였다. 큰 오차에 민감하지만 이것은 제외를 정당화하거나 일차 결과를 바꾸는 근거가 아니다. C07을 빼도 계획 변동이 사라지지 않는다. 효과 크기·후보 해상도·관측 규모·원래 학습 구조의 범위가 함께 작용하며, 단일 원인으로 확정하지 않는다.

## 7. 실제 새 do 표본 검산

실행 전에 `mc_calibration_v1/PLAN_v1.json`과 SHA를 저장했다. 고정 causalAssembly FCM 모듈(commit `8da3729e6383f0e1cbe7740bb6ab7ac4977ac7f9`, SHA `c1f1b7f6b62c8916ebd23cb0002cdad1e9fcfb995b81cfae9558271987c4290e`)을 수정하지 않고 사용했다. 외부 제조 generator 전체 검증이 아니다.

## 8. 정밀도 계획과 새 독립 확인 중단

개발 결과를 보기 전에 `DESIGN_GATE_PLAN_v1.json`으로 0.01 개선, 95% 구간 목표 반폭 0.005, 최소18/최대30개 구조, 최대288회 학습, 최대90분의 조건을 기록했다. 0.01은 원래 목표·손실 척도에 대한 설계상 판단값이며 제조 현장의 실용 임계값이라는 근거는 없다. 평균 차이만 0.01을 넘는 것과 구간 하한 전체가 넘는 것은 다르다. 향후 안정적 추가 정보 주장은 A 다음 B의 고정 순서로 두 하한이 모두 0.01을 넘어야 한다.

계획식 `ceil((1.96×구조별 차이 SD/0.005)^2)`에 전체 및 사전 구조군 변동 중 큰 값을 적용했다. A는 150개, B는 129개 구조가 필요했다. 150개×3자료×3알고리즘=1,350회로 범위를 넘는다. 확정 정책만으로 계산한 사후 정밀도 민감도는 1,218개로 더 나빴다. 이 값은 작은 개발 구조군에서 얻은 대략적 구간 폭 계산이며 충분한 검정력을 보증하는 정확한 표본 수가 아니다. 원하는 우세를 얻기 위한 반복 중단 규칙도 아니다.

동일 구조에서 학습 반복을 늘리면 학습 잡음은 줄일 수 있어도 구조 간 변동을 없애지 못한다. 먼저 독립 구조 수가 필요하다. 실제 개입 표본을 늘려도 구조 수가 늘지 않는다. 따라서 **새 독립 구조 0개, 새 학습 0회, 독립 확인 NOT_RUN**이다. 설계 Gate를 통과한 것처럼 축소된 확인 실험을 실행하지 않았다. 새 구조 목록·계수·seed 또는 독립 결과를 임의 생성하지 않았다. 이번에 모든20구조로 저장한 예측기는 개발용 고정 산출물이며 새 확인 성능이 없는 상태다.

## 9. 다음 실제 구현·실행 조건

1. 과제 특징의 저차원 표현과 예측기의 복잡도를 개발 자료에서만 비교하고 구조 전체 검증으로 안정성을 확인한다. 모델·특징·손실 척도 변경은 개발 버전으로 기록한다. 현재 고차원 모형을 독립 자료에 바로 확대하지 않는다.
2. 수정 없는 후보 예측기에서 구조 단위 정밀도·계산 예산을 다시 계획한다. 정밀도 기준/예산 변경이 필요하면 근거와 대안을 명시한다. 사전 판단에 충분한 새 구조 수·규칙·계수·seed·모델을 확정하기 전에는 확인 자료를 생성하지 않는다.
3. 조건을 통과하면 추천을 먼저 고정한 새 독립 구조에서 M1→M4, M5→M6을 평가한다. 이론 손실을 일차 기준으로 유지하고 실제 do 표본을 별도 검산한다. 제조 환경 동등성·복구·안전성은 별도 미해결 과제다.

가설에 대한 답은 현재 다음과 같다. **경로 복원율은 추천 규칙을 넘어 효과 예측과도 관련되는 개발 증거가 있지만, 연결·방향 정확도와 과제·알고리즘·정책을 고려한 안정적인 추가 정보는 아직 독립적으로 확인되지 않았다.**
