# TEP 6분 경계 최종 검토

ENVIRONMENT_PLAUSIBLE_UNVERIFIED. 기존 원본과 복원 설정225·10초의 330~420초 73센서·12명령 및 모델 내부 cache·밸브 상태를 research_runs/tep_final_handoff/BOUNDARY_330_420.csv에 기록했다. 원본의 내부1.8초 이력은 관측하지 못하며 모델 cache와 원본 제어 명령은 다른 시점이다.

360초까지 핵심 값이 맞고 370초부터 작은 차이가 나타난다. 0.1시간 가스 분석기·조성 제어 갱신과 계산 호출 순서가 후보이나 원본 내부 상태와 실행 순서를 확보하지 못했다. 코드에서 mdlOutputs의 상태 계산, mdlDerivatives의 명령 cache 갱신, 분석기 지연 및 잡음 호출을 확인했다. 결과는 B: 잡음·계산·기록 차이가 누적될 수 있으나 단일 원인은 미확인이다. 과거의0·36초 설정과 원본225·10초 차이는 확인·복원했다. 장기 동일성과 원본→1499행 가공은 미확정이다. 새로운 시뮬레이션은 수행하지 않았다.

공식 모델의 XMV10 실제 개입은 기술적으로 성공했지만 한 쌍의 −0.038°C를 평균 효과로 해석하지 않는다. 상세 역할과 연구 경로는 docs/handoff/TEP_WEEKEND_HANDOFF_20261031.md 참조.
