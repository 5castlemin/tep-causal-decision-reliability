# 복원 감사 보고

## 확인된 원본과 우선순위

동결된 7개 그래프 ZIP과 Step 6 결과 CSV를 최종 구조 산출물로 판단했다. 각 자료의 경로·해시는 `ARTIFACT_INVENTORY.md`에 있다. 보고서보다 행렬·결과 CSV·동결 설정을 우선했다. 10월 사전점검 자료는 그래프를 SCM에 연결하기 위한 **설계와 호환성 검사**이지 적합·개입 결과가 아니다.

정상 데이터는 무명 인덱스를 제외한 1,499×31이다. 원본 GT 33×33에서 X27과 X31을 제외한 평가용 GT에는 방향 간선 28개가 있다. 7개 행렬은 행=원인, 열=결과 규약을 따른다고 기존 검증기가 확인했다. Step 6의 엄격한 방향 F1은 방향 미확정 쌍을 분모에 포함하고 정방향 확정 쌍만 TP로 인정한다. SHD는 누락·추가·역방향·방향 미확정을 쌍당 1회 수정으로 계산한다. U규칙은 폐루프 10쌍에 한정한 보조 기준이며 결과 열람 뒤 도입되었다.

현재 12개 과제는 9개 XMV×22개 XMEAS의 198쌍에서 GT 방향 경로 65쌍을 생성하고, 대표성을 고려하여 사람이 정한 목록을 코드가 검증한 결과다. 과제들은 경로·조작변수·목표변수를 공유하여 독립적인 12개 표본이 아니다. 점수 기반 자동 최적 과제 목록이 아니다.

이번 복원에서 `src/verify_recovery.py`가 7개 최종 행렬로 기존 Step 6 최종 연결 F1·엄격한 방향 F1·SHD를 독립 재계산해 CSV와 일치시켰다. 무작위 기준선의 10,000회 실험 자체는 다시 실행하지 않았다.

SCM 설계 문서의 정적 4개(PC-stable, BOSS, DirectLiNGAM, DAGMA)는 방향 확정 간선만 쓰는 DAG로 분류됐다. VarLiNGAM·DYNOTEARS는 원래 시차 표현을 쓰는 설계이며, PCMCI+는 동일 시점 순환의 인과계수 식별 문제로 기본 적합이 보류됐다. 학습 대상은 0기반 5..1498(1,494행), 학습 5..1199(1,195행), 검증 1200..1498(299행)이다. 척도 변환은 학습 구간에서만 추정한다. 이것은 **고정된 계획**이었다. 이번 복원에서 6개 적합 가능 그래프의 공통 alpha를 선택하고 정적 3개 그래프를 실제 수치 적합했으며, 그 결과는 `experiments/pilot/logs/normal_fit_summary.json`에 있다. 정상 관측 데이터의 예측 진단일 뿐 개입 효과 검증은 아니다.

## 실행 증거가 부족한 항목

8월 방학 보고서는 TEP 시뮬레이터 소스와 파이썬 연동의 기초 테스트를 **보고**하지만, 현재 조사한 프로젝트·Downloads·연관 ZIP에는 대응하는 소스/API·제어기 설정·재현 명령·실행 로그가 없다. 10월에는 개입 인터페이스가 미확보로 기록됐다. 현재 Gate A를 통과했다고 볼 수 없다. 독립 조작 반응, 이상 주입, 복구·안전 수치는 확인되지 않았다.

## 다음 실험의 선결 조건

1. 시뮬레이터 소스·버전·실행 스크립트·제어기 설정·원시 로그를 확보해 정상 운전과 동일 초기 상태 반복을 재현한다.
2. 조작 가능한 XMV와 Fault 주입을 확인한 뒤, 추정 그래프 점수 없이 복구 과제 1개와 정상·안전 판정 규칙을 확정한다.
3. 공통 선형 SCM 적합 진단과 독립 개입 반응을 분리해 기록한다. 정상상태 예측오차를 인과효과 정확도 또는 복구 성공으로 해석하지 않는다.

감사 범위는 원본 보존과 재현 가능한 최소 복사본이다. 원본 디렉터리·기존 Git 이력에는 쓰지 않았다.
