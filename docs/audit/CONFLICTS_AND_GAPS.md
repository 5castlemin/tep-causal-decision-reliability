# 기록 충돌과 공백

1. **8월 시뮬레이터 가동 보고 vs 10월 개입 인터페이스 미확보.** 8월 23일 보고서 4쪽에는 소스 확보와 파이썬 연동 환경의 기초 테스트 완료가 적혀 있다. 현재 접근 가능한 관련 디렉터리와 압축 파일에서는 실행 코드·버전·명령·원시 로그를 찾지 못했다. 10월 문서의 미확보 상태는 현재 인계 가능한 인터페이스에 관한 것이므로 과거 테스트 주장을 거짓으로 단정할 수 없다. 현재 재현 상태는 **차단**. 해당 팀원에게 코드와 성공 로그를 받아 동일 명령을 다시 실행해야 한다.
2. **논문 1,500표본 vs 공개 CSV 1,499행.** 원인은 추적 문서에서도 미확정. 데이터를 임의 보간하거나 행을 추가하지 않는다. 실제 학습 가능 행은 0기반 5..1498(1,494개)로 고정된 기록을 따른다.
3. **시간 간격.** 공식 비교평가 자료의 3분 빈도는 확인되었으나 원자료 시간과 CSV 각 행의 1:1 대응·무누락 간격은 직접 검증되지 않았다. 시간순 판정은 중간 수준이며 물리적 시차 해석에는 경고가 붙는다.
4. **GT 해석.** 원본 TXT에는 라벨이 없고 X1..X33 순서는 변수표·기존 정렬 코드에 의존한다. 폐루프에서 측정값→밸브 GT 방향과 추정 밸브→측정값은 다른 의미일 수 있다. 엄격한 방향 점수가 기본이며 사후 도입된 U규칙은 보조 진단으로만 둔다.
5. **이전 PCMCI+ 그래프 vs Final.** 이전 과제 ZIP의 Robust A_dir 49간선과 Final 43간선은 다르다. 구조 비교의 입력은 Final ZIP으로 고정한다.
6. **유효표본수.** 다중 시차 자기상관 근사 약 114.4와 AR1 근사 약 410의 차이가 PC/BOSS 설정에 민감하다. 이는 인과발견의 선택 규칙이지 SCM 학습을 114행으로 축소하는 근거가 아니다.
7. **연구 질문 변경.** 이전 질문은 전체 정확도 대 과제 경로 정확도였다. 현재 여러 구조 지표의 후속 의사결정 유용성 비교는 제안 단계다. 결과를 보고 지표를 변경하면 새 버전으로 기록해야 한다.
8. **파일럿의 필수 자료.** Fault 구현, XMV 직접 쓰기/설정값/제어기 출력의 차이, 조작 범위, 정상·안전 임계값, 독립 초기 상태 반복 방법은 미확인. 12개 구조 과제 중 어느 것도 복구 과제로 자동 승격하지 않는다.
9. **PCMCI+ 시차 표현 설명.** 최종 그래프 묶음의 원본 `README.md`에는 시간 전개 그래프를 비순환으로 표현한 문장이 있지만, 이후 호환성 감사에서는 PCMCI+의 시차 0 동시점 순환을 확인했다. 원본 안내문을 수정하지 않고 더 구체적인 후속 순환 감사를 SCM 판단의 근거로 사용한다.
