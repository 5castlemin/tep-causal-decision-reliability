# 실제 복구 과제 명세 — 미확정

현재 12개 과제는 구조 평가용 후보이며 실제 이상 주입·조작 가능성이 검증된 복구 과제는 없다. **Gate B = BLOCKED**. 시뮬레이터 확보 뒤 아래 항목을 모두 채우고 결과를 보기 전에 고정한다.

| 항목 | 현재 상태 |
|---|---|
| 이상 상태(Fault) 식별자·발생 조건·주입 명령·시점 | 미확인 |
| 조작변수(Action) 실제 XMV/설정값 구분·물리 단위·허용 범위·지속시간 | 미확인 |
| 목표 측정변수(Target)·관찰 기간·정상 범위·성공 규칙 | 미확인 |
| 안전 관련 변수·임계값·위반 판정·근거 | 미확인 |
| 동일 초기 상태 반복과 기본 제어 상태 | 미확인 |
| 구조·공정 의미·실행 가능성을 기준으로 한 과제 채택 이유 | 미확인 |

추정 그래프 점수나 예비 SCM 예측을 보고 과제를 선택하지 않는다. 위 항목이 미확인인 상태에서 복구 성공률의 분모나 안전 결과를 만들지 않는다.

2026-10-30: 공식 정상 실행 확보, 동일환경 미확립으로 실제 개입 과제 확정/수행은 보류. 기존 구조 후보를 실행 과제로 승격하지 않음.
