# 오류 위치 독립 확인의 사전 계약·예산

한국어 계약: `docs/research_design/ERROR_LOCATION_INDEPENDENT_CONFIRMATION_PROTOCOL.md`.

- `PLAN.json`: 신규 SCM 생성 규칙,대응 오류쌍,고정 정책/손실,실패·동률,평가와 구조 단위 분석. 실제 SCM·계수·자료가 아님.
- `BUDGET.json`: 옛 구조별 차이/시간 메타데이터 및 산술. 새 손실 차이의 검정력이나 실행시간 보장이 아님.
- `GATE.json`: **REDESIGN_REQUIRED**,실행 불가. 미해결은 정밀도–독립SCM 자원과 종단 비용 근거의2개.
- `EVIDENCE.json`: 읽은 기존 입력 hash. 시작 상태 문서의 당시 hash는 별도로 기록하며 이후 정상 상태 갱신과 혼동하지 않음.
- `validation/`: 실제 정적/산술/보존·기존 검사 기록. 신규 실험/최종 검정 아님.

현재 실행 명령은 없다. 기존 다양화 runner가 이 신규 계약을 구현했다고 주장하지 않으며,이번에는 generator/runner/새 검사 코드를 추가하지 않았다. 새 SCM/관측/발견/수치SCM 적합/do/최종 검정은0이다. 기존 단위검사의 과거 수치 적합/CV 재검산은 별도 저장 기록 검증이다.

잠정30개와 비교 자원90분은 승인된 실험 예산이 아니다. 다음 한 가지는 반폭0.1을 위한 독립 SCM 자원 투입 여부 또는 확인 확대 종료 결정이다. 자동 후속 기술 시험·문서 루프나 TEP 재개는 없다.
