# 운전 차이의 근거와 미확정 원인

- **직접 확인:** 공식 2015 보관 `MultiLoop_mode1.mdl`의 17개 PI 블록의 비례 계수·적분 시간·표본 주기·표시된 출력 한계를 Studio registry의 대응 정의와 비교한 결과 모두 수치가 같다. `CONTROL_DIFFERENCES.csv`는 각 블록과 숫자를 기록한다. workspace 변수 기반 초기 출력·런타임 내부 기억·실행 순서 및 연결 전체의 동일성은 이 비교로 확인되지 않는다. 원본의 블록 이름 `xmv4`에 `2800`이 쓰인 예처럼 이름만으로 공정 입력 포트를 식별해서는 안 된다.
- **직접 확인:** Studio 기본 setpoint는 초기 측정값으로 만들어지고 5/9/12 명령은 22.21/47.446/50이다. 문헌은 조정된 정상 운전에서 5/9 폐쇄, 12 100%라고 보고한다. 현재 1499행의 특정 원본 파일과 그 고정 명령이 연결되었는지는 미확정이다. 현재 33개 전처리 전 열과 export 코드 부재로 X27/X31 제거 이유도 직접 확인하지 못했다.
- **직접 확인:** B의 1.519시간에 XMEAS15 측정치 100.623554%는 Studio schema의 스트리퍼 액위 상한 100%를 넘는다. native 종료 코드는 0이었다. 기존 PR #28 원시 기록의 동일 시점 값도 똑같다. 이전 2시간 실행은 비유한값과 native 종료가 없었다는 결과이지 이번 측정 제약 통과를 의미하지 않는다. 측정 잡음이 포함될 수 있어 내부 실제 액위가 물리 한계를 넘었다고 단정하지 않는다.
- **직접 확인:** B 중단 시 압력은 2612.875 kPa이고 압력 제어 출력은 purge 비율 r5=0.00006425, XMV6 명령=0.10715%로 하한에 가깝다. 실제 B에서 목표 세 개를 동시에 바꿨으므로 어떤 설정 또는 포화가 압력 불일치의 원인인지 식별하지 못한다. 제어기 부호 `Kc=-1e-4` 및 압력→purge 비율→purge 밸브 경로는 코드·공식 PI 파라미터에서 확인된다.
- **미확정:** 공식 모델과 Studio는 각각 ode45와 0.0005h 고정 RK4이며 정량 영향은 미검사. 제어기 초기 기억·출력 제한, 과도상태, 생산량/유량 비율, 원본 보호 기능, 표본/센서 지연·잡음, 원본 후처리는 각각 가능 원인이지만 단일 요인 대조 없이 원인으로 확정할 수 없다.
- **다음 증거:** Manca의 정상 원시 실행, 시간·명령·seed·model flags·실행 및 전처리 파일과 기존 CSV의 정확한 계보. 공식 MATLAB의 같은 초기·입력·제어 기억 trace가 있으면 비교 강도가 높아진다. 외부 연락은 수행하지 않았다.
